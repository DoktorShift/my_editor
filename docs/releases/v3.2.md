# MyEditor v3.2

## Highlights

- **Sign out actually signs you out** - signing out of Nostr left the profile picture and name rendering in the header chip, so the app looked signed in when it was not. The signer session really was dropped, only the display was stale. Fixed.
- **A cleaner Save Changes prompt** - the unsaved-changes dialog is now sized to its content instead of padded out with empty space, and its buttons render the same on Linux, macOS, and Windows rather than picking up whatever the desktop theme imposed.
- **No more app name in dialog titles** - dialog titles read `Save Changes?` instead of `Save Changes? - MyEditor`, which had been truncating to `Save Changes? - MyEdit` on narrower windows. This affected Linux and Windows; macOS never showed the suffix.
- **Now formally open source under the AGPL** - the repository ships the full GNU AGPL-3.0-or-later license text, a License section in the README, and SPDX headers on every tracked Python file. Copyright is attributed to rinbal.

## Technical updates & fixes

- `AvatarStore` never implemented `pop()` after it replaced a plain dict, so `_on_nostr_sign_out` raised `AttributeError` and aborted before `_profile_store.remove()` could run. Added `pop()` to the store's dict-shaped surface, with regression tests covering the removal path.
- Dropped `setApplicationDisplayName`. Qt's xcb, wayland, and Windows platform plugins append that value to every window title via `QPlatformWindow::formatWindowTitle`; the Cocoa plugin does not. `setApplicationName` still identifies the app, and Qt falls back to it for windows with an empty title, so the main window title is unchanged.
- Replaced the stock `QMessageBox` save prompt with a purpose-built dialog that fits its content and paints its own button badges, so it does not depend on desktop icon themes. All four call sites (closing a modified tab, quitting, closing the window, and the pre-update save prompt) share one helper.
- SPDX-FileCopyrightText and SPDX-License-Identifier headers added across 99 tracked source files.
