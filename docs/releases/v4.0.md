# MyEditor v4.0

## Highlights

- **A real writing editor** - Edit, Insert and Format menus with each platform's own keys, a format toolbar and a format bar over selected text, with real lists, checklists, quotes, tables, footnotes, code blocks, links, Find and Replace, and a word count with reading time.
- **Faster writing** - type `/` for a menu of styles, blocks and inserts, turn on Markdown Shortcuts to format as you type, and Undo takes back whole runs of typing.
- **Your font and your size** - choose the writing font and its size in Settings, zoom with View > Zoom In and Zoom Out, and make selected text bigger or smaller with Format > Bigger and Smaller.
- **Spelling as you type** - the system's own spell checker underlines mistakes on macOS, Windows and Linux, with suggestions, Learn Spelling and Ignore Spelling on right-click.
- **Write, Preview and Split** - see a document as text, as a preview, or side by side; with a Nostr account, the preview shows exactly what Nostr will show.
- **Lock a document with a password** - File > Set Password... encrypts it in place in the open age format (it opens without MyEditor too), crash backups included.
- **Dictate and listen** - Start Dictation uses your Mac's dictation or Windows Voice typing, and dictates offline on this computer where there is none (Linux, or Windows by choice) after a one-time 161 MB download; Edit > Speech reads a draft aloud.
- **MyEditor in German** - View > Language switches the whole app to German; controls are named for screen readers, focus is always visible, and Appearance can follow the system.
- **Keyboard first** - MyEditor 3.3's keys work on every system, Ctrl+Tab and F6 move between tabs and panels, and Help lists every shortcut.
- **Nostr accounts without a signer app** - create, restore and back up an account in the app, keep the key on this computer or move it to a signer app, and edit your profile.
- **Article Details, live on the page** - title, summary, cover and hashtags in one inspector and at the top of the page, with a 16:9 cover crop and front matter kept as written.
- **Co-authors and shared zaps** - credit co-authors and share an article's zaps with them, the same way Standup does.
- **Mentions, quotes and media** - type `@` to mention someone, quote notes and articles, insert audio and video, and preview a post before publishing.
- **Drafts and Published, redesigned** - drafts grouped by date with a full preview on Space, and a Published view that opens your posts in Standup Discover, njump and other readers.
- **Imports window** - sources, posts and articles in one window, feeds checked while the app runs, the list shared with Standup.
- **Media Library, rebuilt** - drag files in, filter and search, and Quick Look plays audio and video and previews PDFs.
- **EINUNDZWANZIG membership** - apply and pay by Lightning from the Nostr menu, and use the members' media server.
- **Updates that keep your work** - Software Update installs in place on every system, checks every download, and brings every tab back after the restart.

## Technical updates & fixes

- New dependencies: `PyYAML` (front matter is checked by a real parser before it is written), `rubicon-objc` on macOS (the system spell checker and dictation), `pyrage` (age encryption for locked documents), and `sherpa-onnx` with `sherpa-onnx-core` on Windows and Linux (offline Whisper dictation with the Silero voice detector).
- Newly bundled Qt modules: QtMultimedia (playback and video posters) and QtTextToSpeech (Edit > Speech). The .deb depends on `libpulse0` and recommends `libenchant-2-2`. Read aloud on Linux uses `speech-dispatcher`, and the app says so when it is missing.
- Dictation models download only after the person chooses to, from their makers (Hugging Face and the sherpa-onnx releases) over HTTPS, each file pinned to its size and SHA-256. The same verified download (`verified_download.py`) now serves the R Markdown toolchain.
- Builds install from hashed lock files for all three systems (`packaging/requirements-*.lock`), and every bundle runs `my-editor --self-test` before it becomes an installer: translations, icon, TLS, signing and encryption, lazily loaded modules, spelling, the Markdown round trip, media, speech, and the dictation engine.
- CI runs the full suite (about 7,400 tests) and the translation check on Windows, macOS and Linux for every pull request.
- One source of truth each: `markdown_writer.py` for every Markdown file, draft and article; `commands.py` for menus, the slash menu and the shortcut list; `atomic_file.py` for every file write, which keeps permissions, Finder tags and line endings and never damages a file on a full disk.
- Nostr: outbox routing (NIP-65), relay sign-in (NIP-42), private draft relays (NIP-37), deletion requests (NIP-09), password-protected keys (NIP-49), NIP-05 verification, mentions and quotes (NIP-27, NIP-18), audio and video metadata (NIP-92), HTTP auth (NIP-98), and the media server list (kind 10063).
- Fix: every addressable event puts its `d` tag first, so relays that read the first tag as the address no longer replace one article with another.
- Security: a Nostr secret key is never pasted into prose, published or sent to a search relay; keys kept on this computer live in a file only the account can read; copied secrets leave the clipboard after a minute; relays others name may not point into the private network; and public copies of pictures lose their hidden data.
- The membership service holds the association's API key on its own server (`sidecar/`), so the key never ships in the app.
- Help > Show Log Files opens a small diagnostic log (warnings and errors only, never keys or text) to attach to bug reports.
- Ctrl+C or a request to stop in a terminal quits the same way File > Quit does.
- Fixes: Format's Style and Color menus could vanish after a right-click, taking new tabs with them; line numbers sat one line above their line; HTML documents reopened in monospace at 14 px; a detached preview lost its cover; Open in Standup Discover always fell back to njump; the full preview could not be scrolled; emoji shifted mentions, selections and Find results; closed tabs now free their memory.
